# Visitor IP Tracking System - Admin Guide

## Overview
A secure system has been implemented to track and collect visitor IP addresses and detailed information invisibly in the background. Only you (the admin) can view this data through a password-protected admin page.

## What Information is Collected?
For each visitor, the system automatically logs:
- **IP Address** - The visitor's IP address
- **Timestamp** - Date and time of visit
- **Browser** - Which browser they're using (Chrome, Firefox, Safari, etc.)
- **Operating System** - Their OS (Windows, macOS, Linux, Android, iOS)
- **Referer** - Where they came from (Google, direct visit, etc.)
- **Page Visited** - Which page they accessed
- **User Agent** - Full browser/device information

## Features

### 🔍 Search Functionality
Use the search box to filter logs by:
- IP address
- Browser name
- Operating system
- Any other field

### 📥 Export to CSV
Click the "Export CSV" button to download all visitor data as a spreadsheet for further analysis.

### 🔄 Auto-Refresh
The data is updated in real-time. Simply refresh the page to see new visitors.

### 🗑️ Auto-Cleanup
The system automatically keeps only the last 1,000 visitor entries to prevent the log file from becoming too large.

## Files Created

1. **includes/visitor-tracker.php**
   - Background script that collects visitor information
   - Runs automatically on every page load
   - Stores data in `visitor-logs.json`

2. **admin-visitor-logs.php**
   - Secure admin dashboard
   - Password protected
   - Beautiful interface with statistics and export features

3. **visitor-logs.json**
   - JSON file storing all visitor data
   - Located in the root directory
   - Automatically created when first visitor arrives

## Security Features

✅ **Password Protection** - Only authorized users can access logs
✅ **Session-Based Authentication** - Secure login system
✅ **Invisible to Visitors** - Tracking happens in the background
✅ **No External Services** - All data stored on your server
✅ **Logout Function** - Secure logout to end admin session

## Important Notes

1. **Privacy Compliance**: Ensure you comply with privacy laws (GDPR, CCPA, etc.) in your region. Consider adding a privacy policy mentioning visitor tracking.

2. **File Permissions**: Make sure the web server has write permissions to create `visitor-logs.json` in the root directory.

3. **Change Default Password**: The default password is `royal2026admin` - change this immediately for security!

4. **Backup Logs**: Periodically download/backup the visitor logs using the CSV export feature.

5. **Hide Admin Page**: Consider renaming `admin-visitor-logs.php` to something less obvious (e.g., `secure-panel-xyz123.php`) for additional security.

## Troubleshooting

**Problem:** Can't access admin page
- **Solution:** Make sure you're using the correct URL and password

**Problem:** No visitor data showing
- **Solution:** Check that `visitor-logs.json` file was created and has write permissions

**Problem:** "File not found" error
- **Solution:** Ensure all files are uploaded to the correct directory on your server

## How It Works

1. When someone visits your website, `index.php` loads
2. It automatically includes `visitor-tracker.php`
3. Visitor information is collected and saved to `visitor-logs.json`
4. The visitor sees nothing - it's completely invisible
5. You access `admin-visitor-logs.php` to view all collected data
