## 🚀 Quick Start

### Windows
1. Double-click `setup.bat`
2. Open `index.html` in your browser

### Mac/Linux
1. Run `chmod +x setup.sh`
2. Run `./setup.sh`
3. Open `index.html` in your browser

### Manual Setup
1. Extract all files to a folder
2. Open `index.html` in a modern web browser
3. For form functionality, upload to a PHP-enabled server

## 📧 Contact Form Setup

### Requirements
- PHP 7.0 or higher
- Mail server configured

### Configuration
Edit `script.php` and update:
```php
$config = [
    'recipient_email' => 'your-email@example.com',
    'from_email' => 'noreply@yourdomain.com',
    // ... other settings
];
```

### Testing Locally
For local testing without a mail server:
1. Use a service like Mailtrap or MailHog
2. Or modify `script.php` to save to a file instead
