## 🚨 Why Email is Failing Locally

The error you're seeing:
```json
{
    "success": false,
    "message": "Failed to send email. Please try again later or contact us directly."
}
```

**Reason:** PHP's `mail()` function requires a properly configured mail server. On your local Windows machine, there is no mail server configured, so emails cannot be sent.

### **Option 2: Configure Local Mail Server (Advanced)**

#### For Windows (Using XAMPP):

1. **Install XAMPP** (if not already installed)

2. **Configure sendmail** in XAMPP:
   - Edit `C:\xampp\sendmail\sendmail.ini`
   - Add Gmail SMTP settings:
     ```ini
     smtp_server=smtp.gmail.com
     smtp_port=587
     smtp_ssl=tls
     auth_username=your-email@gmail.com
     auth_password=your-app-password
     force_sender=your-email@gmail.com
     ```

3. **Edit php.ini**:
   ```ini
   [mail function]
   sendmail_path = "C:\xampp\sendmail\sendmail.exe -t"
   ```

4. **Create Gmail App Password**:
   - Go to Google Account → Security
   - Enable 2-Step Verification
   - Generate App Password
   - Use that password in sendmail.ini

5. **Restart Apache**

### **Option 3: Use PHPMailer (Best for Production)**

PHPMailer is more reliable than PHP's `mail()` function.

#### Installation:
```bash
composer require phpmailer/phpmailer
```

#### Sample Code:
```php
<?php
use PHPMailer\PHPMailer\PHPMailer;
use PHPMailer\PHPMailer\Exception;

require 'vendor/autoload.php';

$mail = new PHPMailer(true);

try {
    // Server settings
    $mail->isSMTP();
    $mail->Host       = 'smtp.gmail.com';
    $mail->SMTPAuth   = true;
    $mail->Username   = 'your-email@gmail.com';
    $mail->Password   = 'your-app-password';
    $mail->SMTPSecure = PHPMailer::ENCRYPTION_STARTTLS;
    $mail->Port       = 587;

    // Recipients
    $mail->setFrom('noreply@yourdomain.com', 'Royal Albatross Exports');
    $mail->addAddress('royalalbatrossexports@gmail.com');
    $mail->addReplyTo($email, $name);

    // Content
    $mail->isHTML(true);
    $mail->Subject = '[Website Inquiry] New Inquiry from ' . $name;
    $mail->Body    = $emailBody;

    $mail->send();
    echo 'Message has been sent';
} catch (Exception $e) {
    echo "Message could not be sent. Mailer Error: {$mail->ErrorInfo}";
}
?>
```

## 🐛 Troubleshooting

### Email not sending on Namecheap?

**Check 1: Email account exists**
- Verify in cPanel → Email Accounts

**Check 2: From email matches domain**
```php
// ❌ Wrong - different domain
'from_email' => 'noreply@gmail.com'

// ✅ Correct - same domain
'from_email' => 'noreply@yourdomain.com'
```

**Check 3: Check spam folder**
- Emails might be in spam initially

**Check 4: Check error logs**
- cPanel → Error Logs
- Look for mail() errors

**Check 5: Contact Namecheap support**
- They can verify mail() is enabled
- Usually enabled by default

## 📧 Email Delivery Tips

### Improve Deliverability:

1. **Use domain email** - Not Gmail/Yahoo
2. **Set up SPF record** - In cPanel DNS
3. **Set up DKIM** - In cPanel Email Authentication
4. **Avoid spam words** - In subject/body
5. **Test with multiple emails** - Gmail, Outlook, Yahoo

### SPF Record (cPanel):
```
v=spf1 include:_spf.mx.cloudflare.net ~all
```
