## 🔧 How It Works

### **1. Visitor Detection**
```php
// Creates unique identifier from:
- IP Address
- User Agent (browser info)
- Hashed for privacy
```

### **2. Uniqueness Logic**
- Visitor is "unique" if not seen in last 24 hours
- After 24 hours, same visitor counts as new
- Old records automatically cleaned up

### **3. Data Storage**
- Stored in `visitor-counter.json`
- JSON format for easy reading
- Automatically created on first visit

### **4. Counter Updates**
- Total visits: Incremented on every page load
- Unique visitors: Incremented only for new/returning (24h+) visitors
- Data saved immediately

## 🔧 Configuration

### **Change Uniqueness Window**

Edit `includes/visitor-counter.php` line 27:
```php
// Current: 24 hours
$oneDayAgo = $currentTime - (24 * 60 * 60);

// Change to 1 hour:
$oneDayAgo = $currentTime - (1 * 60 * 60);

// Change to 7 days:
$oneDayAgo = $currentTime - (7 * 24 * 60 * 60);
```

### **Change Display Format**

Edit `includes/footer.php` line 52-56:
```php
// Current format:
👁 1,234 visits • 👥 567 visitors

// Change icons:
<i class="fas fa-chart-line"></i> <?php echo number_format($visitorData['total_visits']); ?> views

// Change separator:
<span style="margin: 0 8px;">|</span>

// Remove unique visitors:
<!-- Just show total visits -->
```

### **Hide Counter**

Comment out in `includes/footer.php`:
```php
<!--
<p class="visitor-counter" style="...">
    ...
</p>
-->
```

## 🧪 Testing

### **Test the Counter:**

1. **First Visit:**
   - Refresh the page
   - Check footer: "1 visit • 1 visitor"

2. **Refresh Page:**
   - Refresh again
   - Check footer: "2 visits • 1 visitor"
   - (Same visitor, so unique count doesn't increase)

3. **Wait 24 Hours:**
   - Come back tomorrow
   - Refresh page
   - Check footer: "3 visits • 2 visitors"
   - (Now counted as new unique visitor)

4. **Different Browser:**
   - Open in different browser
   - Check footer: Unique visitors increases
   - (Different user agent = different visitor)

## 🔒 Security & Privacy

### **What's Stored:**
- ✅ Hashed visitor identifiers (MD5)
- ✅ Timestamps
- ✅ Counter numbers

### **What's NOT Stored:**
- ❌ Raw IP addresses
- ❌ Personal information
- ❌ Browsing history
- ❌ Cookies

### **File Permissions:**
- `visitor-counter.json` should be writable (644 or 666)
- Located in includes/ directory
- Not publicly accessible via URL
